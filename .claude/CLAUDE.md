# TONTON AI

## Règles permanentes
1. Terminer chaque intervention par **`TERMINER SIR`**
2. Questions **une par une** avant de coder
3. **Ne jamais lancer `npm start`**
4. Travailler sur une **branche** (`feat/...` ou `fix/...`), ouvrir une **PR** vers `main` — plus de push direct
5. Pusher la branche, puis merger via PR après review du collaborateur
6. Faire `git pull --rebase` avant chaque push
